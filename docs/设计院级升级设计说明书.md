## 2. 模块 A · 发电量精算（GB 50797）

### 2.1 输入
- 站址：经纬度或地区（决定气象与太阳位置）
- 阵列：倾角 β、方位角 γ、安装方式（固定/最佳倾角/平铺）、行间距遮挡系数
- 组件（型号库）：额定功率 Pstc、效率、**功率温度系数 γ_P**（≈ -0.35%/℃）、NOCT、首年/逐年衰减
- 逆变器：额定、**效率曲线 η(负载率)**、**容配比 DC/AC**（1.0~1.3）
- 系统损失：线损、失配、积灰污染、遮挡、可利用率、MPPT 效率

### 2.2 气象与辐照（weather.js）
- TMY 逐时 GHI、Tair（内置地区近似 TMY 关键参数库；支持用户上传逐时辐照 CSV）
- 太阳位置（赤纬/时角/高度角/方位角，经典天文公式）
- **倾斜面辐照 POA**（各向同性 / Hay 模型）：`POA = Hb·Rb + Hd·(1+cosβ)/2 + ρ·H·(1-cosβ)/2`

### 2.3 出力模型（pvmodel.js）
```
Tcell = Tair + (NOCT-20)/800 · POA
Pdc   = (POA/1000)·Pstc·(1+γ_P·(Tcell-25))·(1-soiling)·(1-mismatch)·衰减(y)
Pac   = Pdc·η_inv(负载率)·(1-线损)·可利用率，并受逆变器额定钳位（弃光）
PR    = Σ Pac / (Σ POA/1000 · Pstc)        // 系统效率
等效利用小时 = 年发电量 / 装机
```

### 2.4 P50 / P90（投资/银行口径）
- 年际辐照变异系数 σ（地区相关，5%~7%）
- `P90 ≈ P50·(1 - 1.282·σ)`，同理给 P75/P95；逐年叠加组件衰减
- **输出**：逐时/逐月/年发电、PR、等效小时、P50/P90、首年与全周期。

## 3. 模块 B · 储能精细化建模（GB 51048）

### 3.1 电池与寿命
- SOC 区间 [SOCmin, SOCmax]（如 5%~95%）、往返效率 η_rt（含 PCS）
- **SOH 衰减**：`SOH = 1 - k_cyc·EFC - k_cal·t`
  - EFC：年等效满充放循环数（由调度累计放电量/可用容量得）
  - 循环寿命与 DOD 相关（Wöhler 曲线/rainflow 简化）；日历寿命独立项
  - 到 EOL（如 80%）触发**更换**，计入更换投资
- **自耗电**：温控/BMS 辅助功率（%额定/h），计入运营成本与购电
- 备用容量（应急/需量备用）占用

### 3.2 调度策略（被 engine 调用）
- 一充一放 / **两充两放**（两谷两峰）自动择优
- 目标：套利 + 需量削峰（受变压器/报装约束）+ 反送约束下绿电消纳
- **输出**：年放电量、年循环数、SOH 曲线、更换年份、**LCOS（平准化储能度电成本）**

### 3.3 收益模式（接入财务）
- 自用套利、需量管理（降基本电费）、**容量租赁/共享储能**（元/MW/年 或调峰补偿元/MWh）

## 4. 模块 C · 可研级财务评价（经济评价方法与参数·第三版）

### 4.1 投资构成（动态投资）
```
静态投资 = 设备购置 + 建筑安装 + 其他费用 + 预备费
建设期利息 = Σ 各期贷款·利率·(建设期占用)
动态投资(总投资) = 静态投资 + 建设期利息
资本金 = 总投资·(1-贷款比例ρ)；  贷款 = 总投资·ρ
```

### 4.2 融资与还款
- 贷款比例 ρ、利率 i_loan、期限 n、宽限期、**还款方式**：等额本金 / 等额本息
- 逐年：还本、付息、本金余额；**DSCR=可用于还本付息现金/还本付息额**，**ICR=息税前利润/利息**

### 4.3 收入与成本（逐年）
- 收入：电费节省 + 余电上网 + 充电服务费 + 容量租赁 + 绿证 + 碳收益（模块F 提供）
- 成本：运维（分项：组件清洗/设备维护）、保险（%投资）、人工、屋顶租金/分成、储能自耗电、大修（周期性）
- **折旧**：直线法，折旧年限（光伏/储能）、残值率
- **税务**：
  - 增值税：销项-进项，期初留抵逐年抵减
  - 企业所得税 25%，**"三免三减半"**（前 3 年免、4~6 年减半）可开关
  - 附加税（城建+教育附加，按增值税 ~12%）

### 4.4 三大报表（逐年，result.statements）
- **现金流量表**（全投资 / 资本金两套）：经营/投资/筹资现金流、净现金流、累计
- **利润表**：营业收入、成本、折旧、利息、利润总额、所得税、净利润
- **资产负债表（简化）**：资产（在建/固定/货币）、负债（长期借款）、所有者权益

### 4.5 指标
- **项目 IRR / 资本金 IRR**、行业基准 i_c（**待你确认：8% 或 6%**）下 NPV
- 静态/动态回收期、LCOE（拆解）、DSCR（最小/平均）、ICR、总投资收益率、资本金净利润率

### 4.6 敏感性与盈亏平衡
- 单因素 ±5%/±10%（造价、电价/利用小时、贷款利率、运维）→ IRR/NPV 龙卷风图
- 盈亏平衡电价 / 平衡利用小时

## 5. 模块 D · 电气一次系统（工程估算级）

- **接入电压判定**：≤400kW→380V；0.4~6MW→10kV；>6MW→35kV（可调阈值）
- **容配比** DC/AC（1.0~1.3）→ 逆变器/PCS 容量
- **变压器选型**：`S = Pmax/(cosφ·负载率)` → 取标准容量序列（…630/800/1000/1250/1600/2000 kVA…）
- **反送/逆流约束**：允许/不允许/限流比例（影响余电上网与弃电）
- **无功补偿**：目标 cosφ=0.95，补偿容量 `Qc = P·(tanφ1-tanφ2)`
- **线损**：按电压等级与距离的简化百分比
- **主要设备规格表**：组件、逆变器、PCS、电池、变压器/箱变、电缆、支架、汇流箱…规格×数量（喂给 BOM）

## 6. 模块 E · 8760 逐时仿真引擎

- **负荷 8760**：由 12 月电量 × 逐时 shape × 工作日/周末/季节系数合成；或直接用导入的 15 分钟数据聚合到 8760
- **光伏 8760**：气象驱动（模块A）
- **逐时滚动调度**：储能 SOC 状态机（谷充峰放/两充两放/削峰/反送约束/自耗电）
- **多典型日**：4 季 ×（工作日/周末）= 8 典型日 加权（快速档）；或完整 8760（精算档）
- **性能**：单年 8760 逐时；25 年按衰减/价格缩放叠加（避免 21.9 万步）；必要时 Web Worker 后台计算并显示进度
- 与现有 `simplified/professional` 并存为第三档 `engineering`

## 7. 模块 F · 政策与市场机制

- **分布式上网模式**：自发自用余电上网 / 全额上网（标杆或指导价）/ 全部自发自用（三选一）
- **隔墙售电（就近交易）**：交易电价 + 过网费
- **绿电/绿证**：绿证收益（元/MWh）、绿电溢价
- **现货市场**：可选导入分时现货价曲线，放大储能套利
- **需求响应**：邀约/容量补偿（元/kW·次 或 元/MWh）
- **CCER 碳收益**：减排量 × 碳价（元/tCO₂）
- 以上统一作为收入项接入模块C 财务。
