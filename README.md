# 新能源投资测算软件 ⚡

**光伏 · 储能 · 充电桩 · 柴油发电机** —— 单选或任意组合，内置 AI 智能配置与投资测算。

一个**纯前端、零依赖、打开即用**的新能源投资测算工具，PC / 手机自适应。面向投资决策，帮助快速评估"光储充柴"各种组合方案的经济性。

---

## ✨ 功能特性

| 模块 | 能力 |
|---|---|
| 📊 **方案测算** | 四种设备自由组合，输出 IRR / NPV / 回本期 / LCOE / 25 年现金流 / 碳减排 |
| 🤖 **AI 容量优化** | 在预算 / 场地 / 负荷约束下，自动搜索光伏+储能最优容量组合（目标可选：NPV 最大 / 回本最快 / 收益率最高） |
| ⚙️ **储能策略寻优** | 自动比较"峰谷套利 / 套利+削峰 / 套利+平段充电"三种调度策略，选出最优 |
| 🔮 **负荷/发电预测** | 由月电费、峰值负荷或行业类型反推年用电量与逐时曲线；按地区光照预测光伏发电 |
| 💬 **AI 对话助手** | 用大白话描述需求，自动解析参数 → 测算 → 推荐方案 |
| 🌍 **多地区** | 内置华东/华北/华南工商业、户用、海外示例，电价/光照/政策可切换、可编辑 |
| 🎯 **双档精度** | 简化快速版（代表日）与专业逐时版（8760 小时季节仿真）一键切换 |

## 🚀 运行方式

无需安装、无需构建、无需联网：

```bash
# 方式一：直接用浏览器打开
open index.html              # macOS
# 或双击 index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器的 file:// 限制）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

手机端：把整个目录部署到任意静态托管（GitHub Pages / Vercel / Nginx）即可访问，界面自动适配。

## 🧮 测算逻辑（符合市场）

- **光伏**：按地区等效满发小时计年发电，区分自发自用与余电上网，含首年/逐年衰减、残值。
- **储能**：逐时调度——谷段充电、峰/尖峰放电套利，余电优先充储；可选需量管理削峰；计入循环效率、容量衰减、到寿更换成本。
- **充电桩**：服务费收入型资产，按桩数×功率×利用率测算电量与毛利。
- **柴油发电机**：备用/调峰，计入油耗、油价、碳排放，以"替代尖峰购电"体现调峰价值。
- **电价机制**：分时电价（尖/峰/平/谷）+ 两部制需量电费，逐地区可配置。

> ⚠️ 测算结果基于工程估算与公开市场参数，**仅供投资决策初筛参考**，最终请以实际工程设计与当地电价政策为准。

## 🔌 接入大模型（可选升级）

对话助手默认使用内置的「规则 + 语义抽取」引擎，离线可用。
如需更自然的对话理解，可在 `js/assistant.js` 的 `callLLM` 钩子中接入大模型 API：
解析自然语言为结构化参数后，仍复用本地 `Forecast` / `Optimizer` / `Engine` 完成测算，
确保数字可解释、可复算。
